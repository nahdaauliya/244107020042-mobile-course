# Refleksi

- Kapan native lebih tepat dipilih daripada cross-platform?
Jawaban: Native lebih tepat dipilih saat aplikasi membutuhkan performa yang sangat tinggi, akses mendalam terhadap fitur atau API khusus suatu platform.
- Bagaimana perubahan state berhubungan dengan widget tree dan UI deklaratif? 
Jawaban: Perubahan state menyebabkan widget yang terdampak di-rebuild, sehingga UI otomatis diperbarui sesuai kondisi state terbaru.
- Mengapa commit kecil dengan pesan jelas bermanfaat bagi pekerjaan tim dan portfolio? 
Jawaban: Agar perubahan mudah dilacak, dipahami, dan dikembangkan bersama tim, sekaligus menunjukkan proses kerja yang terstruktur dalam portfolio.
